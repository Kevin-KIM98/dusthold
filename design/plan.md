# DUSTHOLD (가칭) — 게임 기획서 v0.1.2

> 지상에서는 안개 낀 타일을 하나씩 열어 자원을 모으고,
> 지하에서는 벙커를 층층이 파 내려가며 방을 짓고 생존자를 배치한다.
> 밤마다 좀비가 방폭문을 두드린다. 무선실을 완성해 구조 신호를 보내면 1장 클리어.

- 장르: 싱글플레이 생존 경영 + 탐험 (실시간, 일시정지·배속 가능)
- 플랫폼: 브라우저 (모바일 세로 화면 우선, PC도 동작)
- 시점: **지상 = 탑다운 타일 맵**, **벙커 = 옆에서 본 단면도** — 하단 탭으로 전환
- 원작 참고 장르: 타일 탐험형 생존 전략 + 벙커 단면 경영. **이름·캐릭터·로고·아트는 전부 오리지널.**
- 1차 목표: 플레이 가능한 프로토타입(1장, 약 30~45분 분량). 재미 확인 후 Unity 이식 여부 결정.

## 시간 규칙

| 항목 | 값 |
|---|---|
| 하루 | 240초 (낮 180초 + 밤 60초) |
| 배속 | ×1 / ×2 / ×3, 일시정지 |
| 습격 | 매일 밤 시작 시 |
| 1장 목표 | 무선실 완성 (보통 8~12일차) |

## 시작 상태

- 생존자 4명 (특기 채집·건설·전투·기술 1명씩)
- 벙커: 방폭문 Lv1, 승강기 샤프트 1~2층, **1층에 발전실 1개 + 정수실 1개 완성**, 나머지 칸은 흙
- 지상: 입구 주변 8칸 밝혀짐 (숲·폐허·농지 최소 1개씩 보장)
- 첫 밤 전에 수경재배실을 지을 수 있도록 시작 자원 배분 (식량 20·물 20·목재 40·고철 25)

## ① 오브젝트 목록

### 생존자

| 항목 | 값 | 비고 |
|---|---|---|
| 시작 인원 | 4명 | 이름 랜덤(오리지널 이름 풀) |
| 체력 | 100 | 부상(체력 40 이하) 시 일 못 함 |
| 특기 | 채집 / 건설 / 전투 / 기술 중 1개 | 특기 일 배치 시 효율 +50% |
| 소비 | 하루 식량 2, 물 2 | 부족 시 굶주림 → 매일 체력 -30 |
| 배치 가능 | 방 근무 / 공사 / 원정대 / 지상 채집 / 경비 / 휴식 | |
| 전투력 | 5 (전투 특기 8, 무기 +5) | 원정·경비에 사용 |

### 벙커 방 (단면도 칸 단위, 칸 = 1w)

| 방 | 크기 | 건설비 | 공사 시간* | 전력 | 근무 최대 | 효과 |
|---|---|---|---|---|---|---|
| 방폭문(입구) | 고정 | - | - | 0 | - | 체력 300. 강화 Lv2=600(고철40), Lv3=1000(고철80·목재20) |
| 승강기 샤프트 | 1w | 목재10 | 10초 | 0 | 0 | 층 연결. 시작 시 1~2층 있음 |
| 발전실 | 2w | 고철25·목재10 | 30초 | +6/근무자 | 2 | 전력 생산 |
| 정수실 | 2w | 고철15·목재10 | 25초 | -3 | 2 | 물 +4/일/근무자 |
| 수경재배실 | 2w | 목재20·고철10 | 25초 | -3 | 2 | 식량 +4/일/근무자 |
| 숙소 | 2w | 목재20 | 20초 | -1 | 0 | 인구 상한 +4 (시작 상한 6) |
| 창고 | 1w | 목재15 | 15초 | 0 | 0 | 자원별 저장 상한 +100 (시작 150) |
| 작업장 | 2w | 목재20·고철20 | 30초 | -4 | 2 | 제작: 무기(고철15, 전투력 +5), 도구(목재10·고철5, 채집·건설 속도 +25%), 탐사 장비(고철20, 원정 시간 -25%) |
| 경비실 | 1w | 고철20 | 20초 | -2 | 2 | 경비 1명당 습격 좀비에 초당 5 피해 |
| 자동 포탑 | 입구 부착 | 고철40 | 25초 | -4 | 0 | 초당 8 피해 (최대 2기) |
| 의무실 | 2w | 목재15·고철15 | 25초 | -3 | 1 | 부상자 회복 체력 +40/일 |
| 무선실 ★ | 2w | 고철80·목재40·통신부품1 | 60초 | -10 | 1 | 완성 시 1장 클리어 |

\* 공사 시간은 건설 인원 1명 기준. 2명이면 ×0.6, 건설 특기면 ×0.67. **굴착**(빈 칸 파기)은 칸당 목재5 + 10초.

### 지상 타일 (11×11, 중앙 = 벙커 입구)

| 타일 | 등장 거리(링) | 탐험 보상 | 채집 | 비고 |
|---|---|---|---|---|
| 숲 | 1~ | 목재 15 | 목재 6/일/인, 매장량 120 | |
| 폐허 | 1~ | 고철 10 | 고철 4/일/인, 매장량 80 | |
| 농지 | 1~ | 식량 10 | 식량 5/일/인, 매장량 100 | |
| 저수지 | 2~ | 물 15 | 물 6/일/인, 무한 | |
| 보급 상자 | 1~ | 랜덤 자원 20~40 | - | 1회성 |
| 생존자 캠프 | 2~ | 생존자 +1~2 (상한 초과 시 대기) | - | |
| 좀비 둥지 | 2~ | 클리어 시 고철 30 | - | 전투력 10×링 필요. 미제거 시 밤 습격 +2마리 |
| 군 기지 | 4~5 | **통신부품 1** + 고철 40 | - | 전투력 35 필요, 맵에 1곳 고정 |

- 탐험: 이미 밝혀진 타일에 **인접한** 안개 타일만 가능. 원정대 1~3명, 소요 = 20초 × 링 거리(왕복 포함).
- 지상 채집은 **낮에만**. 밤이 되면 자동 귀환(귀환 중 습격받지 않음).
- 맵은 시드 기반 랜덤 생성, 링별 등장 비율은 config에서 조정.

## ② 자원 · 경제 규칙

| 자원 | 종류 | 시작값 | 주 획득처 | 주 소비처 |
|---|---|---|---|---|
| 식량 | 저장 | 20 | 수경재배실, 농지 | 생존자 하루 2 |
| 물 | 저장 | 20 | 정수실, 저수지 | 생존자 하루 2 |
| 목재 | 저장 | 40 | 숲 | 굴착·건설 |
| 고철 | 저장 | 25 | 폐허, 둥지 | 건설·제작·문 강화 |
| 전력 | **흐름(저장 안 됨)** | 생산 0 | 발전실 | 방 가동 |
| 통신부품 | 특수 | 0 | 군 기지 | 무선실 |

- **저장 상한**: 자원별 150, 창고 1개당 +100.
- **전력망**: 승강기 샤프트에 (직접 또는 이웃 방을 거쳐) 가로로 이어진 방만 전력망에 연결. 끊긴 방은 꺼짐.
- **전력 부족**: 소비 > 생산이면 우선순위 낮은 방부터 꺼짐 (우선순위: 경비실·포탑 > 정수실 > 수경재배실 > 의무실 > 작업장 > 숙소 > 무선실). 꺼진 방은 단면도에서 어둡게 + 번개 아이콘.
- **인구**: 생존자 수 ≤ 인구 상한. 초과로 들어온 생존자는 입구에서 대기(숙소 지어지면 입주).
- **굶주림/갈증**: 하루 정산(새벽) 때 식량·물이 모자라면 모자란 인원 체력 -30. 체력 0이면 사망.
- 생산 단위 "/일"은 하루 240초에 걸쳐 연속으로 쌓인다 (내부적으로 초당 값으로 환산).

## ③ 적 AI 행동 (밤 습격)

- **시작**: 매일 밤 시작(180초 시점) 지상 맵 가장자리 랜덤 방향에서 등장 → 입구로 이동(이동 10초).
- **마릿수**: `min(4 + 2×(일차−1) + 2×(미제거 둥지 수, 링3 이내), 40)`
- **5의 배수 날 = 대규모 습격**: 마릿수 ×1.5
- **공격**: 입구 도착 후 방폭문을 계속 공격. 경비·포탑이 가장 앞 좀비부터 피해.
- **방폭문 파괴 시 (침입)**: 남은 좀비가 1층으로 들어와 방 하나씩 공격 → 방 고장(수리: 해당 방 건설비 30% + 10초), 그 층 생존자 체력 -20/초당 접촉. 침입 상태는 새벽에 종료(남은 좀비는 생존자 전원이 싸워 처치, 대신 전원 체력 -15).
- **새벽 처리**: 방폭문 체력은 다음 낮 동안 고철 소모 없이 초당 1% 자연 회복.
- **지상 원정 전투**: 둥지·군 기지는 즉시 판정. `원정대 전투력 ≥ 요구치`면 승리, 아니면 전원 부상 귀환(보상 없음). 승리해도 요구치의 50% 이상이었으면 1명 체력 -20.
- 수치는 전부 `js/config.js`에 모아두고 밸런싱 단계에서 조정.

## ④ 조작 체계

### 모바일 (기본)
| 동작 | 지상 | 벙커 |
|---|---|---|
| 탭 | 타일 선택 → 정보 패널 | 방/빈 칸 선택 → 정보·건설 패널 |
| 드래그 | 맵 이동 | 단면도 위아래·좌우 스크롤 |
| 핀치 | 줌 (0.6~2.0) | 줌 (0.6~2.0) |
| 길게 누르기 | - | 생존자 잡아서 다른 방으로 옮기기 |

### PC
- 좌클릭 = 탭, 드래그 = 이동, 휠 = 줌
- 단축키: `Space` 일시정지, `1/2/3` 배속, `Tab` 지상↔벙커 전환, `Esc` 패널 닫기
- WASD 카메라 이동은 **넣지 않음**(단축키 충돌 방지).

### 배치 방식
- 정보 패널의 `+ 배치` 버튼 → 쉬는 생존자 목록에서 고르기 (드래그 없이도 전부 가능해야 함)
- 원정대: 타일 선택 → `탐험` → 1~3명 선택 → 출발

## ⑤ 화면 구성 (세로 모바일 기준)

```
┌───────────────────────────┐
│ 식량 물 목재 고철 ⚡전력 👥인구 │ ← 상단 자원 바 (부족하면 빨간색)
│ ☀ 3일차 14:20  습격까지 0:42 ⏸×1│ ← 시계·습격 카운트다운·배속
├───────────────────────────┤
│                           │
│   [지상 맵] 또는 [벙커 단면]   │ ← 메인 캔버스
│                           │
├───────────────────────────┤
│ 선택 정보 패널 (접이식)       │ ← 탭한 대상의 정보·버튼
├───────────────────────────┤
│  🗺 지상  |  🏚 벙커  | 📜 기록 │ ← 하단 탭
└───────────────────────────┘
```

- **지상 맵**: 안개 타일(어둡게), 밝혀진 타일(종류 아이콘), 원정대 이동 표시, 채집 중 인원 수, 밤엔 화면 어둡게 + 좀비 이동.
- **벙커 단면**: 지표면(흙·풀) 아래 층별 칸, 굴착 안 된 칸은 흙. 방 안에 근무자 표시, 천장을 따라 전선·배관 선이 그려짐(전력망 연결 시각화).
- **공사 연출** (광고 느낌의 핵심):
  - 굴착: 흙 파편 파티클 + 곡괭이 든 일꾼 + 진행바
  - 건설: 비계(scaffold) → 골조 → 완성 3단계 그림 전환, 작업자 왕복 애니메이션, 지상 입구 위에 크레인 표시
  - 완성: 반짝 효과 + 전선이 이어지며 불이 켜짐
- **기록 탭**: "숲 탐험 완료 · 목재 +15", "방폭문 피해!" 같은 로그
- **알림 토스트**: 습격 30초 전 경고, 굶주림 경고, 원정 귀환
- **오버레이**: 1장 클리어(구조 신호 송신), 게임 오버(생존자 전멸), 첫 실행 튜토리얼 힌트 5개

## ⑥ 완료 기준 (체크리스트) ★

각 항목은 검수 단계에서 테스트 하나가 된다.

**뼈대**
- [ ] index.html을 열면 콘솔 에러 0건으로 타이틀 → 게임 화면이 뜬다
- [ ] 상단 바에 자원 6종과 인구가 표시되고 값이 바뀌면 즉시 갱신된다
- [ ] 시계가 흐르고 180초에 밤으로 바뀌며 240초에 다음 날이 된다
- [ ] 일시정지·×2·×3 배속이 시뮬레이션 속도를 실제로 바꾼다
- [ ] 새로고침해도 진행 상황이 복원된다(10초마다 자동 저장)

**지상**
- [ ] 시작 시 입구 주변 8칸만 밝혀져 있고 나머지는 안개다
- [ ] 밝혀진 타일에 인접한 안개 타일만 탐험할 수 있다
- [ ] 원정대를 보내면 링 거리×20초 후 귀환하며 타일이 밝혀지고 보상이 들어온다
- [ ] 숲·폐허·농지에 생존자를 배치하면 낮 동안 자원이 쌓이고 매장량이 줄어든다
- [ ] 밤이 되면 지상 채집 인원이 자동 귀환한다
- [ ] 둥지 공격 시 전투력이 부족하면 부상 귀환, 충분하면 클리어되고 다음 습격 마릿수가 줄어든다
- [ ] 군 기지를 클리어하면 통신부품 1개를 얻는다

**벙커**
- [ ] 샤프트에 이어진 빈 칸을 굴착하면 목재가 빠지고 진행바 후 칸이 열린다
- [ ] 자원이 부족하면 건설 버튼이 비활성화되고 이유가 표시된다
- [ ] 방 건설이 비계 → 골조 → 완성 3단계로 보이고, 건설 인원 수에 따라 시간이 줄어든다
- [ ] 발전실에 근무자를 넣으면 전력 생산이 오르고, 근무자를 빼면 내려간다
- [ ] 전력이 부족하면 우선순위 낮은 방부터 꺼지고 어둡게 표시된다
- [ ] 샤프트와 끊긴 방은 전력망에서 빠져 작동하지 않는다
- [ ] 정수실·수경재배실 근무자가 있으면 물·식량이 늘어난다
- [ ] 숙소를 지으면 인구 상한이 4 오른다
- [ ] 식량이나 물이 0인 채로 새벽이 오면 생존자 체력이 30 줄어든다

**습격**
- [ ] 밤 시작 시 공식대로의 마릿수가 맵 가장자리에서 입구로 몰려온다
- [ ] 좀비가 방폭문 체력을 깎고, 경비·포탑이 좀비를 처치한다
- [ ] 방폭문이 부서지면 1층 방이 고장 나고 생존자가 다친다
- [ ] 5일차 습격이 평소의 1.5배 규모다

**목표·종료**

## 성능 상한

2D Canvas 게임이므로 draw call 대신 **"한 프레임에 그리는 개수"**와 **"캐시"**로 관리한다.

| 항목 | 상한 | 지키는 법 |
|---|---|---|
| 목표 프레임 | PC 60fps / 중급 폰 45fps+ | 아래를 지키면 자연히 달성 |
| 최악 장면 | 위 성능 항목 참조 | 이 장면을 디버그 키(`F9`)로 즉시 생성해 측정 |
| 지상 타일 | 121칸 | 정적 타일 레이어는 오프스크린 캔버스에 1번 그려 재사용, 바뀔 때만 다시 그림 |
| 벙커 칸 | 최대 7열 × 8층 = 56칸 | 흙·벽 배경은 캐시, 방 내부와 사람만 매 프레임 |
| 좀비 | 동시 40마리 | 스프라이트 시트 1장, 객체 풀 재사용 |
| 파티클 | 동시 150개 | 객체 풀, 상한 넘으면 오래된 것부터 제거 |
| 캔버스 해상도 | devicePixelRatio 최대 2로 제한 | 고해상도 폰에서 과부하 방지 |
| 이미지 | 아틀라스 PNG, 장당 2048px 이하 | 프로토타입은 도형으로 대체 |

## 기술 구조

- **단일 HTML + ES 모듈, 빌드 도구 없음.** Canvas 2D. 외부 라이브러리 없음.
- **고정 타임스텝** 시뮬레이션(1틱 = 0.1초), 렌더는 requestAnimationFrame.
- **로직과 화면 분리**: `js/sim/`은 DOM·캔버스를 전혀 모름 → Node로 헤드리스 테스트 가능.
- **시드 랜덤**: 맵 생성·습격 방향은 시드 RNG → 테스트 재현 가능.
- 저장: localStorage, 버전 번호 포함(구조 바뀌면 마이그레이션 또는 초기화).

